## Major accomplishments

### Bootstrap APK automation (new device deployment — Mac only)
- **`android_apk` resign support** — new `resign`, `apksigner_bin`, `keystore`, `keystore_pass`, `key_alias` params for unsigned fork builds
- **`bootstrap_apks` role** — version-aware install of 7 prerequisite APKs (Termux, Termux:Boot, Termux:API, Shizuku, AutoJs6, Tailscale, Obtainium) over ADB before SSH exists
- **`ensure-bootstrap-apks.yml`** — playbook wired into `site.yml` before preflight
- **Version-aware idempotency** — each APK: query `gh release view` for latest tag, compare against installed versionName, install only when stale
- **Termux:Boot first-launch** — monkey-launched after install to un-stop package for BOOT_COMPLETED

### Shizuku start module
- **`shizuku_start` Ansible module** — starts Shizuku over ADB without device interaction
  - Attempts `HEADLESS_START` broadcast first
  - Falls back to direct `libshizuku.so` native launch (works for first-time pairing)
  - Applies fleet profile (TCP mode, start-on-boot, watchdog)
  - Verifies port 5555 is open via `/proc/net/tcp` grep
  - 16 unit tests covering all pure functions and module integration paths
- **`ensure-shizuku.yml`** — playbook wired into `site.yml` after APK ensure, before SSH bootstrap

### Preflight APK version check
- **`verify-bootstrap-apks.yml`** — fails early with clear list of missing or stale APKs
- **`check_apk.yml`** — per-APK checker with accumulator pattern (`_vfy_results` list)
- Tested on s24: all 7 APKs confirmed current
