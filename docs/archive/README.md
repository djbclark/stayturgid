# Archive — historical documents

Everything under `docs/archive/` is a **historical record**: completed or
superseded plans, old session logs, and handoffs whose content has been
overtaken by later work.

**Do not read this directory to learn the current state of the project.**
Current state lives in [docs/STATUS.md](../STATUS.md); open work lives in
[GitHub issues](https://github.com/djbclark/stayturgid/issues) and
[docs/options.md](../options.md).

These files are kept verbatim (including any stale claims and dead links they
contain) because the repo's rule is to never rewrite historical session or
research records to make the present look cleaner. Filenames keep their
original dates.

| Subdirectory | Contents                                                            |
| ------------ | ------------------------------------------------------------------- |
| `plans/`     | Completed or superseded implementation plans and priority orderings |
| `sessions/`  | Old session logs and superseded handoffs                            |
